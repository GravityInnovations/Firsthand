A clear path for every report

Simple for the person reporting it. Useful for the people fixing it.

Firsthand is deliberately split into small parts, so recording, interpretation and issue creation stay clear, secure and replaceable.

01

Record the moment

Your user captures their screen and adds a short explanation while the problem is still in front of them.

02

Prepare the report

The transcoder turns the user’s written context and transcript into a structured report. The video stays out of the model request.

03

Review and send

The user can check and edit the report before the reporter stores the evidence and creates the GitHub issue.

Designed to fit your stack

Three focused components.
One better feedback loop.

Use the recorder in any web product. Run the services separately. Keep permanent credentials on the server, not in the browser.

See how to implement it →
  1. 1
    Recorder

    Small browser component that captures the user’s explanation, page context and optional recording.

  2. 2
    Transcoder

    Creates an editable developer report from text and locally transcribed audio.

  3. 3
    Reporter

    Stores the approved evidence, creates the GitHub issue and keeps user-specific issue history.
